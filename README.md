# NFSMW-2005-Archipelago
This is my first mod for any game, and I didn't see that many car racing games, so I decided why not?

So this is a bit finicky, and may need some changes in the files, somethings that weren't really tested was the Bounty system option yet, and is a work in progress.

The installer may also have some issues as I had never actually made an installer before so I'm including everything else so it can all be dragged and dropped.

This does use some AI mostly for reverse engineering as I stated in the discord.

Requirements:
To Run this you will need the Black Edition(Note: I don't have the normal version so I wasn't able to test it.), and it will need to be Version 1.3 of the game. You will know if it's the 1.3 version if the file size of the speed.exe file looks like this:

As stated, the installer may have some issues, so I'm including the client.exe, and the scripts as well.

The files in the Scripts file will need to be added to your NFSMW scripts file, all of it, without it, the game will not run.
